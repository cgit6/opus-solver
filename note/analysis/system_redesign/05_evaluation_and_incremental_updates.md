# 05｜evaluate、真實適應值與增量更新

狀態：評估與增量更新原則已確認；通用型別、隨機評估上下文與細部計數待定。對應 D07、D11–D12、D16。

## evaluate 的語意

```text
evaluate(一個個體的完整編碼)
  → (真實適應值, 是否可行)
```

概念上包含兩項問題責任：依目標函數算分、依限制式判斷可行性。布林值以 true 表示可行，不要和 `violates_constraints()` 的 true 表示違反限制混用。

回傳後由算法把結果寫回同一個體的解狀態。evaluate 本身不是 addAct，也不自動提交歷史。

數學上可評分、但違反限制的候選解，仍可有真實目標值。格式損壞或目標未定義等情況，不能硬填零分假裝正常；正式錯誤契約另議。

## 真實目標值與搜尋分數分開

例如路線的真實成本為 437，而算法對不可行解加 100：

```text
真實目標值 = 437
算法罰分   = 100
搜尋分數   = 537
```

算法可以用 537 做搜尋決策，但不能對外說這條路線的原始成本就是 537。罰分與搜尋分數可以保存在內部或外部結構。

這是新設計的責任原則，不等於本次已修改舊 SCVRP 的輸出契約。現有 legacy 的三種分數與相容行為必須明確對照後才遷移，詳見 [12](12_prior_work_and_references.md)。

## 不必每移除一個物品就全部重算

以下是說明用的三物品背包，不是實際題庫：

| 物品 | 價值 | 重量 | 價值／重量 |
| --- | --- | --- | --- |
| 1 | 12 | 4 | 3 |
| 2 | 6 | 3 | 2 |
| 3 | 9 | 3 | 3 |

容量為 7，目前三件都選：

```text
編碼 = [1, 1, 1]
真實適應值 = 27
負載 = 10
可行 = false
```

算法選擇移除 CP 最低的物品 2。一次完整小操作如下：

```text
編碼[2]：1 → 0          # 這裡用人類第 2 件的編號，不指定程式索引
真實適應值：27 - 6 = 21
負載：10 - 3 = 7
可行：7 <= 7 → true
```

完整重算的結果也是 12 + 9 = 21。因此可以直接更新原來的分數與負載，不必再次掃完整編碼。

若是多限制背包，每個受影響的負載都要更新；只扣價值卻保留錯誤容量緩存，仍是不完整操作。

## 誰負責哪一段

- 挑哪件物品移除、CP 如何用於修復順序：算法策略。
- 移除對價值與各限制負載的影響：依問題規則正確計算。
- 寫回同一個體的編碼／分數／負載：算法操作。
- 完成後要不要 addAct：算法選擇。
- 任務結束核對最終解：求解任務。

可在問題內提供增量工具，也可由算法使用問題數值實作；不先要求所有問題都有通用 `delta` 框架。非加法目標、路線成本與 AI 訓練不能一律套用「減掉一個物品價值」。

## 紀錄不負責補救分數不同步

正確順序是「完整更新編碼和相應狀態 → 提交」。不是先改編碼，再期待 addAct 自動 evaluate 把分數修好。

對已有分階段更新的 legacy 算法，遷移時必須找出完整操作界線，不能為了紀錄插入額外評估而改變原本接受判斷或 RNG。

## 目標函數可能使用 RNG

確定性背包／距離計算通常不需要 RNG，但系統不能假設所有問題都如此。帶噪聲 benchmark、抽樣模擬、ML 訓練與隨機切分，都可能使用隨機來源或可變狀態。

本次查閱的現有 `ContinuousProblem` 明確使用 deterministic objective；f07 的註冊名稱是 `f07_weighted_quartic_deterministic`。不能把來源書籍的帶噪版本和目前註冊版本混為一談；更不能由此推論未來問題全部確定。

所以：

- addAct 不重新 evaluate、不重抽樣、不重新訓練。
- 不以「保存並恢復全域 RNG」當作通用補救；模型、快取、I/O、GPU 等副作用未必能回復。
- 隨機評估的正式 seed 分工／重播上下文仍需另定；不先替換所有現有 RNG。
- 最終驗證應核對對應的評估規則與必要上下文，不能只拿另一次隨機分數做不恰當的相等判斷。

## 未來驗收

- 對每個增量操作，用完整 evaluator 對照正確性。
- 固定相同初始狀態，比較操作後編碼、真實分數、負載與可行性。
- 要求 bit 級重現的浮點算法，檢查計算順序；不能自行改用較寬容誤差掩蓋差異。
- 測記錄開關不增加評估／RNG 消耗。
- 明確定義增量更新是否計入 evaluation_count；此細項尚未定案。

以上是待執行驗收，不是本次新測試結果。
