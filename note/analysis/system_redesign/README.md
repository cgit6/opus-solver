## 狀態用語

- **已確認**：使用者已明確接受的需求或責任，不因整理文件而重新變成建議。
- **待討論**：提出過或有合理方向，但尚未接受具體方案；未確認的範例不等於正式 schema。已確認的停止子設定以 D61 及 [18](18_experiment_configuration_and_task_expansion.md#已確認的群組停止欄位) 為準。
- **延後處理**：知道有需求或風險，現在明確不納入實作。
- **現況核對**：依各節查閱日期記錄程式／既有文件所見；本輪輸入檢查於 2026-10-23 查閱，較早觀察保留原範圍，不代表目標設計已實作或重新跑過測試。

細節文件可以同時包含不同狀態；以各節標示為準。不能因為某份文件標題出現某個技術，就認定它已被選用。
