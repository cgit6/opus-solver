# C++ 優化算法模擬平台設計

建立日期：2026-10-25。

本方案以 C++ 建立完整優化算法模擬平台，Python 保留為 AI 問題的資料準備、模型訓練與候選解評估模組。這是新的平台設計方向，不再以「Python 實驗系統呼叫 C++ 求解模組」作為架構前提。

主方向已依最新討論收斂；程序邊界、並行拓撲、正式資料結構、AI 呼叫及建置方式尚待逐項確認。本輪只建立方案文件，不修改既有程式、算法、設定或註冊，也不搬動題庫。

## 新方案的主體

- **C++ 平台**：實驗安排、設定讀取與檢查、題目準備與持有、任務調度、算法、驗證、狀態紀錄、結果保存及統計。
- **Python AI 問題模組**：依問題定義準備資料、解讀候選編碼、訓練與評分，以及處理需要的模型產物；不另外管理整場實驗。
- **共用流程**：傳統與 AI 問題使用同一套外層任務管理，差別在候選解由 C++ 傳統問題模組或 Python AI 問題模組評估。

優先細化 C++ 準備並持有有型別題庫、算法直接引用的候選。同程序內共用物件不需要每個 task 再解碼共享記憶體，但不代表已決定所有工作都在同一程序，或不再需要任何跨程序交接。
